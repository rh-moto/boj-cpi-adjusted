# 長期CPI系列 改善計画 (YoY-based reconstruction)

## 1. これまでの達成

`docs/long_series_sa_work.md` 参照。3基準（2010/2015/2020）品目別データを chain-splicing で接続し、X-13季節調整を適用、階層集計（小分類〜総合）まで構築済み。

## 2. 発見した構造的課題

### 2.1 1999-12 → 2000-01 ジャンプ

5/81 小分類 (他の娯楽サービス -44%, かばん類 -22%, 設備材料 +37%, 主食的調理食品 +8%, 他の飲料 +7%) で異常ジャンプ発生。品目別では:

| code | 名称 | レベル変動 |
|---|---|---|
| 1401 キャベツ | +22.95% |
| 1406 レタス | +39.21% |
| 1414 だいこん | +22.63% |
| 1434 きゅうり | +21.29% |
| 5111 男子上着 | -19.67% |
| 5181 婦人スラックス冬 | -23.19% |
| 5162 婦人スーツ秋冬 | -25.15% |
| 5183 婦人上着 | -17.83% |

### 2.2 原因解明

3段階で原因を特定:

1. **当方コード由来の可能性を排除**: PDF-spec税調整前後で同じ%変動 → 当方加工なし
2. **2010基準改定で導入された可能性を排除**: 2005基準長期データでも同じ階段 (キャベツ +22.69%, 婦人スーツ秋冬 -25.12% など)
3. **公表YoY系列との比較**: **公表YoYには階段がない** (5111男子上着のレベル -20% に対し、公表YoY 1999-12→2000-01 差は -2.1pp)

→ 真の原因: **1995→2000基準改定時の銘柄スペック変更**で、レベル系列は新銘柄値に切替たが旧銘柄分のリンク係数調整が不完全。総務省は **YoY計算時に内部的な「平滑レベル」を使用**して銘柄変更影響を除去している。

### 2.3 影響範囲

- 1999-12/2000-01 (1995→2000基準改定)
- 同様の階段が他の基準改定境界 (2000→2005, 2005→2010, 2010→2015) にも存在する可能性
- 衣料品 (5xxx) と一部生鮮野菜 (1xxx) で顕著
- 直近 (2015-2026) はsplice境界がデータ品質に問題なく、影響なし

## 3. 改善計画 (案)

### 3.1 基本方針

**公表YoY系列を真値として、レベル系列をYoY整合的に再構築する**。

データソース:
- `data/soumu/longterm/zmy2020_yoy_all.csv` (公表前年同月比、2020基準・全744品目・1971-2026)
- `data/soumu/cpi_2010base_items.csv` (公表レベル、2010基準・1970-2016) — アンカー値として使用

### 3.2 再構築アルゴリズム

各品目について:

1. **アンカー設定**: 2010年12ヶ月分のレベル値を `cpi_2010base_items.csv` から取得（基準年なので spec change 影響なし）
2. **遡及計算**: t < 2010-01 では `level(t) = level(t+12) / (1 + YoY_published(t+12)/100)`
3. **順次計算**: t > 2010-12 では `level(t) = level(t-12) × (1 + YoY_published(t)/100)`
4. 2015年以降は **2015基準パイプライン由来のレベル**を chain-splice (2010基準アンカーから2015基準への接続)
5. 2021年以降は **2020基準パイプライン**を chain-splice

これにより、銘柄変更による階段が排除された滑らかなレベル系列が得られる。

### 3.3 後続処理（変更なし）

1. **特殊要因調整** (`policy_events.csv` + PDF-spec):
   - 消費税: 1997-04, 2014-04, 2019-10
   - 教育: 2010-04 高校無償化, 2019-10 ECE無償化, 2020+, 2024+, 2025+
   - エネルギー補助金: ガソリン/灯油/電気/ガス (2022+)
   - モバイル: 2021-04
   - 旅行支援: GoTo 2020/2022
2. **X-13季節調整** (品目別、上位分類フォールバック)
3. **階層集計** (小分類→中分類→10大費目→総合)

### 3.4 期待される改善

- 1999-12/2000-01 階段解消
- その他基準改定境界での同様問題も自動解消
- 5/81 小分類のジャンプ消失
- 直近はYoYが既に滑らかなので変化なし
- ISM_JP 等の派生指標で 2000年代の異常スパイク解消

## 4. 検証方法

1. **YoY整合性**: 再構築後の `level(t)/level(t-12)` が公表YoYと一致するか
2. **基準改定境界の連続性**: 1999-12/2000-01, 2000-12/2001-01, 2005-12/2006-01 等で月次変化率が異常値でないこと
3. **2010年アンカー保存**: 2010年12ヶ月の値が公表 `cpi_2010base_items.csv` と一致すること
4. **直近期間 (2015-2026) の不変性**: 既存実装と差がないこと

## 5. リスク・残課題

- **公表YoY系列が無い品目**: e-Stat YoYが含まない品目（追加コードや非公表）はレベルベース処理にフォールバック
- **大幅YoY誤差の累積**: 36年遡及計算で±0.05pp誤差が累積する可能性 → 各5年基準節目で再アンカー
- **負値・ゼロ値**: 高校授業料等で `level → 0` の品目では YoY 計算が破綻 → policy event で別途扱う既存ロジック流用
- **2015-2020基準の splice ratio**: 既存と同じ chain-splicing で良いか確認

## 6. 最終アウトプット (期待)

- `output/cpi_item_long_yoy_based.csv` — YoY整合の品目別レベル系列 (1970-2026)
- `output/cpi_item_adjusted_long.csv` — 特殊要因調整適用 (差し替え)
- `output/cpi_item_adjusted_long_sa.csv` — X-13季調済み (差し替え)
- `output/cpi_aggregated_sa_long.csv` — **小分類指数 + 中分類 + 10大費目 + 総合** (最終目的物)

## 7. Codexレビューを受けた追加方針 (2026-05-04)

### 7.1 致命的リスク
- **なし**。ただし「2015以降は既存レベルをchain-splice」のままだと **2016年・2021年のYoY整合性が崩れる可能性**。月別ratioが一定でない限り、年平均ratioのspliceでは公表YoYと微妙にずれる。

### 7.2 改善提案 (優先度順)

1. **YoY再構築をsplice境界の翌12ヶ月まで延長**
   - 2010アンカーからのYoY再構築を、2016-12 / 2021-12 まで継続。既存2015/2020レベルとの差分を診断してから採用方法を決める。
   - 案A: YoYベースを主系列にし、既存基準系列は新設/欠損品目用にフォールバック
   - 案B: 既存基準系列を主とし、splice後12ヶ月だけYoY整合補正

2. **月別splice ratioの診断**
   - 重複年で `ratio_m = late_base[m] / reconstructed_or_early_base[m]` の月別CVを計算
   - 偏差大きい品目はYoYベース優先 or 月別ratio補正

3. **公表YoY丸め誤差の累積対策**
   - 公表YoYが小数1桁丸めなら36年遡及で誤差累積
   - 1995/2000/2005/2010/2015/2020 の重複アンカーで5年区間内に滑らかに倍率補正

4. **品目コード同一性の明示管理**
   - 既存crosswalk (2010_2015, 2015_2020) を使い以下に分類
     - 完全1:1 / 名称変更1:1 / 新設 / 廃止 / 統合分割 / YoYのみ / レベルのみ
   - **YoY再構築の主対象はまず完全1:1と実質1:1に限定**

5. **YoY意味の確定**
   - 公表YoYが未調整系列であることを入力仕様として明記
   - 何らかの調整済みYoYと混ざっていないことを確認

### 7.3 検証観点 (Codex追加)

1. **YoY整合性**: 全品目・全月で `100 × (level[t]/level[t-12] - 1) - published_yoy[t]` の分布が ±0.05〜0.1pp内か
2. **問題品目境界**: 1401/1406/1414/1434/5111/5162/5181/5183 で 2000-01 の YoYが公表YoYと一致するか
3. **全基準改定境界**: 1999-12, 2000-12, 2005-12, 2010-12, 2015-12, 2020-12 → 翌月のMoM分布
4. **2010アンカー保存**: 2010年12ヶ月の復元値が `cpi_2010base_items.csv` と完全一致 + 年平均≈100
5. **2016/2021 YoY境界**: 2016-01〜12 / 2021-01〜12 の YoY が公表YoYと合うか (**最重要**)
6. **集計後再現性**: 品目別はYoY厳密一致、小分類以上は既存系列差・境界スパイク消失
7. **X-13への影響**: 段差解消によるSA改善 vs YoY丸め由来の微小ギザつき

### 7.4 推奨ステップ

1. YoY再構築を **未調整・品目別レベル** として実装（1:1対応品目に限定）
2. 2010年12ヶ月アンカーから 1971+ 全期間のYoY整合レベルを作成
3. 既存2015/2020基準との重複期間で 月別ratio・YoY差・MoM差を診断
4. 診断結果に基づき、2015以降の処理方針を決定（案A or 案B）
5. 特殊要因調整、X-13、階層集計を既存処理に流す
6. 検証レポート出力（問題品目・全境界・小分類集計・直近差分）

## 8. 真因の再評価と最終判断 (2026-05-04)

### 8.1 仮説の修正

YoY再構築を試作（`scripts/build_item_long_yoy_based.py`）して検証した結果、**当初の「1995→2000基準改定時の銘柄スペック変更が原因」仮説は誤り**と判明:

- 5111男子上着の1999-12→2000-01 -19.7%は**毎年の季節パターン**（1999→00 -19.7%, 2000→01 -20.2%, 2005→06 -22.2%, 2010→11 -22.6%, 2015→16 -17.7%）
- 1401キャベツの+22.95%も同様（毎年同月のMoM変動）
- 公表YoYが滑らかなのは「内部平滑レベル使用」ではなく「季節パターンが両年で同じ」だから

### 8.2 真の原因 (集計時の品目構成変化)

「他の娯楽サービス -44%」「かばん類 -22%」等の**小分類集計レベルのジャンプ**は、品目の登場タイミングのズレが原因:
- 9396 獣医代: 1999-12=NaN, 2000-01=101.9（2000基準で初登場）
- 加重平均が「利用可能品目で再正規化」する設計のため、構成変化で集計値が動く

### 8.3 総務省の公式接続方法

「2020年基準消費者物価指数の解説 第6章」より:
- 接続は地域・総合・類及び品目ごとに独立に行う
- 集計指数（小分類等）も**それぞれ独立にリンク係数で接続**
- 品目から再集計はしない

### 8.4 影響規模の評価

期間別 SA前月比 >10% ジャンプ件数:
| 期間 | 件数 |
|---|---|
| 1971-1989 | 213 |
| 1990-1999 | 42 |
| 2000-2009 | 16 |
| 2010-2019 | 13 |
| 2020-2026 | 11 |

→ **直近 (2010+) でも残るジャンプは大半が生鮮野菜の天候変動**で、構造問題ではない。

### 8.5 最終判断: 現行実装を維持

主用途（景気判断、BOJ Core推計、特殊要因調整）には **現行品目積み上げで実用上十分**。

長期構造分析（30年スパン）が必要になった場合のみ、**Option D**（総務省公表の小分類長期データを直接利用）で対応する。

YoY再構築 (`scripts/build_item_long_yoy_based.py`) は試作として残すが、本番パイプラインには組み込まない。
